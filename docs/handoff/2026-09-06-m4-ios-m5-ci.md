## M4 — iOS 全链路（仅 macOS）

1. **初始化与 FFmpeg 构建**
   - `./init-ios.sh`（n7.1 + `ios/patches-ffmpeg7/`，含 M1–M2 重新生成的
     0100/0101/0102/0103/0106/0202/0222/0303 补丁）。
   - `cd ios && ./compile-ffmpeg.sh all` → `build/universal/`。
   - 注意补丁 0303 新增：libavcodec HEADERS 安装 `packet_internal.h`
     （ijklas.c → libavformat/internal.h → packet_internal.h 依赖链）。
2. **Xcode 工程**
   - 打开 `ios/IJKMediaDemo/IJKMediaDemo.xcodeproj`，编译 IJKMediaPlayer framework
     与 demo；iOS 13 / arm64 / arm64-sim / x86_64-sim。
   - `IJKFFMoviePlayerController.m` 的 FFmpeg 版本由 `init-ios.sh sync_ff_version` 同步。
3. **共享层代码**：`ijkmedia/` 的 n7.1 迁移已在 M2 完成（Android 侧验证），
   详见 `docs/handoff/2026-09-06-m2-ijkmedia-for-ios.md`；iOS 侧编译如遇 API 差异
   按 `/* n7.1: ... */` 风格就近处理。
4. **CMake 参考（可选）**：Android 侧已把 `ijkmedia/ijk{player,sdl,j4a}` 的源码清单
   整理成 CMakeLists（见 `ijkmedia/*/CMakeLists.txt`），iOS 如需复用其源码清单做
   参照，直接读这三个文件即可。

## M5 — CI（GitHub Actions）

目标：Windows runner 验证 Android 链路，macOS runner 验证 Android + iOS 链路。

1. **Android job**（windows-latest，可先 ubuntu 加速迭代）：
   - setup JDK 17（temurin）、Android SDK（android-36, build-tools 36, NDK 28.2.13676358）；
   - `./init-android.sh` → `sh compile-openssl.sh all`（可选，ffmpeg 依赖 openssl）→
     `sh compile-ffmpeg.sh all` → `sh compile-ijk.sh all`；
   - cmake/ninja：runner 自带；ffmpeg configure 需要 make + perl（msys2 已含）；
     x86_64 建议 `choco install nasm` 避免 `--disable-x86asm` 性能回退；
   - `./gradlew assembleDebug`（JDK 17）。
2. **iOS job**（macos-14+）：
   - `./init-ios.sh` → `compile-ffmpeg.sh all` → xcodebuild IJKMediaDemo。
3. 触发：push 到 `ryan-dev` / PR / 手动；缓存 `extra/`、gradle、ffmpeg build 目录
   加速（注意 `module.sh` 永不提交、init 产物全部 gitignore）。
4. Windows runner 注意事项全部在 `docs/knowledge_base/toolchain-baseline.md`
   与 `docs/upgrade/2026-09-06-m1-ffmpeg-n71-baseline.md`（MSYS make、PERL5LIB、
   host-clang、NTFS junction 需求等）。
